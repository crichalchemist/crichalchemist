# Hi, I'm Courtney

**Student and developer in Chicago.** I build full-stack products, privacy-first machine learning, and tools for AI coding agents, often for the people existing software leaves behind.

## What I'm building

### [DigniFi](https://github.com/crichalchemist/DigniFi)
A trauma-informed platform that guides low-income, pro se filers through Chapter 7 bankruptcy with plain-language explanations and auto-filled official court forms. It provides legal information, never legal advice. The MVP is deployed and currently covers the Northern District of Illinois.

**Stack:** Python, Django REST Framework, React, TypeScript, PostgreSQL, Docker, Playwright

### [LeadForge](https://github.com/crichalchemist/LeadForge)
A lead-generation pipeline for Chicago's under-digitized small businesses. It finds them in public data, scores their potential, drafts outreach with LLMs, and makes first contact through AI voice calls, with a React CRM tracking each lead to close. I'm migrating it from Python to Cloudflare Workers, with differential tests that hold the new code to the original behavior.

**Stack:** TypeScript, Hono, Cloudflare Workers, D1, React, Python, FastAPI, PostgreSQL/PostGIS

### [Dignity](https://github.com/crichalchemist/Dignity)
A privacy-preserving deep learning framework for modeling transactional behavior. It applies input-level differential privacy, k-anonymous generalization, and keyed pseudonymization, each backed by a test.

**Stack:** Python, PyTorch, GitHub Actions

### [arscontexta](https://github.com/crichalchemist/arscontexta) (ongoing)
My fork of [agenticnotetaking/arscontexta](https://github.com/agenticnotetaking/arscontexta), a Claude Code plugin that builds a personal knowledge system from conversation. I'm extending it with adapters for Codex, OpenCode, and Pi, maps of content rebuilt from note metadata, and a CI test suite that runs under both bash and zsh.

**Stack:** Shell, Markdown, Claude Code plugins, GitHub Actions

### AI agent tooling
Plugins and harnesses that extend what coding agents like Claude Code can do:

- [token-saver-skill](https://github.com/crichalchemist/token-saver-skill): hands routine coding tasks to free models through OpenCode, saving Claude's context and rate limits for harder reasoning.
- [agent-pi](https://github.com/crichalchemist/agent-pi): runs parallel agents across model providers through Pi, outside Claude's context window.
- [adobe-cli](https://github.com/crichalchemist/adobe-cli): command-line harnesses that let agents and scripts drive Premiere Pro, Illustrator, and Acrobat.
